## Licensing

AIGM-CW follows an **Open Standard, Not Open Use** model.

The canonical specifications may be read and tested freely, but production use,
commercial integration, specification-closure execution, abstraction publishing,
and licensed metamodule execution require an appropriate commercial license.

For the full license terms, see [`LICENSE.md`](LICENSE.md).

### 1. Open Core — Read / Test

**Free**

Includes:

- CCF reading
- CW NodeTypes reading
- CW Rulesets reading
- Editor sandbox mode
- Validator dry-run mode

Does **not** permit:

- Production use
- CI/CD production integration
- External system integration
- Abstraction publication
- Abstraction mounting
- Specification-closure execution
- Metamodule Ruleset execution

> This is an open standard, not open use.
