# Code Node templates

This directory contains copyable templates for code and implementation-context NodeTypes from the current CW Core NodeTypes specification.

The directory is a template catalog only. Placement under `Templates/Nodes/code/` does not assign StructureTree location or canonical identity.

`code.cw` is the canonical `code` / `#FILE` family example. The other files are reusable Node templates commonly used when modeling implementation structure.
